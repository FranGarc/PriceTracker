# Requisitos No Funcionales (NFRs) - App Price Tracker
    Versión: 1.0
    Fecha: 2025-10-02
    Estado: Aceptado

## Mantenibilidad y Operación 
Estos requisitos definen la facilidad para mantener, operar y actualizar el sistema.

- **NFR-1(Cobertura de Código)**: La lógica de negocio principal (el núcleo del dominio) debe mantener una cobertura de pruebas unitarias superior al 80%.
